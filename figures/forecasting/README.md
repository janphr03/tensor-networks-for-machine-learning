The temperature and input-window diagrams use the same invented readings.
The three demand-pattern diagrams are schematic and are not a decomposition
of the temperature readings. `02-simple-patterns.svg` is retained as a legacy asset.
The older diagrams 01–06 below are retained as source assets; Section 2.1 no
longer embeds them. Autocorrelation, random walks, and forecasting strategies
are omitted from this introductory section. Evaluation is introduced in 2.7.

The fifteen SVGs illustrate the forecasting basics and the established methods in the
same visual style as the tensor figures. All values are invented teaching examples,
generated deterministically with fixed random seeds. None of them comes from the
research datasets.

Sections 2.2.3–2.2.4 now use a shared temperature example and five simplified
diagrams from `scripts/build-learning-model-figures.mjs` (included in the full build):
`10-simple-weighted-model.svg`, `11-simple-decision-tree.svg`,
`12-simple-feedforward.svg`, `12-simple-recurrent.svg`, and
`13-simple-attention.svg`. Each diagram follows its explanation without a
visible internal title. Weights, tree thresholds, and outputs are illustrative;
attention is illustrated by two windows with different current patterns,
showing different weights on the same earlier intervals. The mini-curves and
weights are chosen for explanation, not computed by a fitted model; visual
shape matching is not a definition of attention. The diagram is not a complete
Transformer architecture.

Section 2.2.5 uses one comparison, `14-training-starting-points.svg`, from
the same script. It contrasts the same neural network with random initial
weights and with weights learned by pretraining on three schematic datasets.
All numbers and curves are illustrative, not results of a training run.
The former separate diagrams `14-task-training.svg` and
`14-simple-pretraining.svg` are retained as legacy assets and are not embedded.

## Build

Run from the project root:

    node scripts/build-forecasting-figures.mjs

[scripts/forecasting-examples.mjs](../../scripts/forecasting-examples.mjs) defines the
invented data. [scripts/build-forecasting-figures.mjs](../../scripts/build-forecasting-figures.mjs)
draws the figures and writes [manifest.json](manifest.json) with the numbers quoted in
the captions.
