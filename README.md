# Tensor Networks for Machine Learning

Wir untersuchen, ob aktuelle Tensor-Netzwerk-basierte ML-Modelle Zeitreihen aus der Forschungsgruppe unseres Professors genauer oder effizienter vorhersagen können als klassische ML-Modelle.

Dazu analysieren wir die Datensätze und recherchieren geeignete Ansätze aus der aktuellen Literatur. Auf dieser Grundlage wählen wir ein oder mehrere Tensor-Netzwerk-Modelle (z. B. MPS/TT, TTN, MPO oder hybride Ansätze), implementieren bzw. adaptieren sie und vergleichen sie mit passenden Baselines wie DLinear, LSTM oder Transformer.

Bewertet werden Vorhersagefehler, Parameterzahl, Trainings- und Inferenzzeit sowie Speicher- und Rechenbedarf. Ziel ist es, Nutzen, Grenzen und geeignete Einsatzbedingungen der Tensor-Modelle aufzuzeigen und mögliche Weiterentwicklungen abzuleiten. Die Ergebnisse sollen außerdem eine klassische bzw. quantum-inspired Vergleichsbasis für die Quantenalgorithmen der Forschungsgruppe liefern.
