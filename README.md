# Tensor Networks for Machine Learning

Studienarbeit zum Thema **Tensor Networks for Machine Learning**.

Dieses Repository sammelt die Ausarbeitung, Literaturübersicht sowie Code und Experimente zur Studienarbeit.

## Struktur

| Ordner | Inhalt |
| --- | --- |
| `thesis/` | Ausarbeitung, Abbildungen und gegebenenfalls LaTeX-Dateien |
| `literature/` | Literaturverzeichnis und eigene Zusammenfassungen |
| `src/` | Implementierungen und Hilfsfunktionen |
| `notebooks/` | Explorative Analysen und Demonstrationen |
| `experiments/` | Experimentbeschreibungen, Konfigurationen und Ergebnisse |

## Erste Schritte

1. Fragestellung und Gliederung in `thesis/` festhalten.
2. Quellen und eigene Notizen in `literature/` sammeln.
3. Implementierungen in `src/` und Experimente in `experiments/` ergänzen.

Abhängigkeiten und Anleitungen zum Ausführen werden mit den ersten Implementierungen ergänzt.

## Auf GitHub veröffentlichen

Anschließend im Terminal in diesem Projektordner ausführen und `DEIN-USERNAME` durch den eigenen GitHub-Benutzernamen ersetzen:

```powershell

```
